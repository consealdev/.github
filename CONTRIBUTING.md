# Contributing to conseal

conseal is not open contribution: we don't accept pull requests, in any
consealdev repository. Codesense writes every change itself.

## Report a bug

The most valuable contribution is a bug report with the smallest code that
reproduces it. We fix it and credit you in the release notes.

All issues are tracked in one place,
[github.com/consealdev/conseal/issues](https://github.com/consealdev/conseal/issues/new/choose),
for conseal-js, conseal-dotnet and the spec.

## Questions and ideas

Ask in [Discussions](https://github.com/consealdev/conseal/discussions) on
consealdev/conseal: Q&A for how-to questions, Ideas for suggestions.

## Please don't send code

If you have found a fix, describe it in the issue rather than posting a patch.
We write the fix ourselves, and code posted in an issue or discussion is read as
a description of the problem.

## Security

Never report a vulnerability in a public issue. See the
[security policy](https://github.com/consealdev/.github/blob/main/SECURITY.md).
